# 闪聚星球 · 内容工作室

更新日期：2026-09-14。

本工作台为相亲、同城社交与情感内容创作提供四个入口：朋友圈自动运营、小红书 IP 文案、抖音情感文案、生活案例朋友圈。当前界面以用户提供的“闪聚星球 GATHER PLANET”Logo 为品牌依据。

## 品牌约定

- 正式 Logo 使用 `frontend/src/assets/gather-planet-logo.jpg`，为用户原图的原样副本。页面通过 CSS 展示品牌内容，文件没有改色、重绘或裁切。
- 星球黄 `#FFD437` 用于品牌强调，莓果粉 `#CD3B70` 用于主操作，奶油白 `#FFFAF5` 用于背景，深莓色用于正文。
- 视觉应有成年人的相亲、约会、同城相遇与温暖日常的感觉，保留粉色喜好；避免仅替换颜色、满屏强渐变、过多技术术语和与品牌无关的装饰。
- 首页为品牌主视觉、四个内容入口、创作区与流程提示。手机端点选入口后自动滚到创作区。
- 切换创作模式分别保留各自主题；切换作品页、设置页后仍保留当前输入。仅在当前页面会话保留，刷新页面会清空尚未提交的输入。
- 本次只调整品牌展示与前端交互，不更改工作区数据、模型选择、代理授权或现有任务。

## 文件位置

- 品牌样式：`frontend/src/brand.css`
- 基础组件样式：`frontend/src/styles.css`
- 交互与页面结构：`frontend/src/App.tsx`
- 网站标题与说明：`frontend/index.html`
- 原版 Logo：`frontend/src/assets/gather-planet-logo.jpg`
- 原创心动星球插画：`frontend/src/assets/heart-planet.png`

插画是首页装饰图，不是真实活动照片、服务结果或原版 Logo。图片随网站一起本地加载，不依赖外部图片服务。

## 使用与检查

正常使用仍双击已有启动入口，访问 `http://127.0.0.1:5177/`。无需重建工作区、重新导入 IP 信息或改变代理接入方式。

开发时运行 `cd frontend && npm run build`。交付应同时包含源代码、上述品牌素材、说明和 `frontend/dist`。不要打包运行数据库、个人上传素材、登录凭据或本机虚拟环境。

检查范围：桌面端与 320/390/768/1024 像素宽度的布局，Logo 和插画加载，模式选择与独立主题保留，作品/设置往返后的输入保留，手机端滚动定位，已有作品打开与本机代理设置显示。
