## 本轮实现

1. 目标帖子 ID 与详情页实际 ID 不同即返回 `IDENTITY_MISMATCH`，不保存替代帖子。
2. `body_raw` 与 `body_normalized` 分开保存；原始正文不修剪、不合并、不截断。
3. 图片按页面轮播序保存浏览器实际返回的字节，封面单独标识；保存 MIME、尺寸、大小、SHA-256、来源和序号。
4. 每次采集写入独立版本目录，生成 `metadata.json`、`manifest.json`、`checksums.sha256`、`diagnostics.json`、正文文件和 `images/`。
5. `COMPLETE` 只在身份、正文、预期图片、全部字节和文件校验均通过时出现；其余保持 `PARTIAL` 或明确失败状态。
6. 建立持久任务队列、心跳、90 秒采集截止时间、暂停与恢复。登录/验证码暂停；403/429 进入退避，不绕过平台限制。
7. 归档与下载接口按工作区校验。日志和归档只保存去查询参数的来源引用，不保存 Cookie、Token、Authorization 或签名参数。
8. 内容雷达提供“保存原图与正文”、进度、错误、恢复、原始正文、原图和校验证据；链接可直接归档，不依赖旧 OCR 提取完成。
